# Каталог доменных событий

Формат: имя, контекст-источник, семантика, минимальный контракт (ключевые поля).
Общие поля у всех событий: `event_id`, `event_type`, `occurred_at`, `producer`, `version`.

## Зарегистрирован новый пациент
- **Источник:** Medical.
- **Семантика:** в системе заведён новый пациент (без медданных).
- **Контракт:**
  ```json
  { "patient_id": "uuid", "clinic_id": "uuid", "registered_at": "ts", "region": "string" }
  ```

## Пройдено исследование ИИ
- **Источник:** AI.
- **Семантика:** ИИ-сервис завершил исследование.
- **Контракт:**
  ```json
  { "study_id": "uuid", "patient_id": "uuid", "model_version": "string", "status": "completed", "completed_at": "ts" }
  ```

## Создан кредитный договор
- **Источник:** Finance.
- **Семантика:** оформлен новый кредитный договор.
- **Контракт:**
  ```json
  { "loan_id": "uuid", "client_id": "uuid", "amount": "decimal", "currency": "string", "rate": "decimal", "created_at": "ts" }
  ```

## Проведён платёж
- **Источник:** Finance.
- **Семантика:** платёж успешно проведён.
- **Контракт:**
  ```json
  { "payment_id": "uuid", "account_from": "uuid", "account_to": "uuid", "amount": "decimal", "currency": "string", "paid_at": "ts" }
  ```

## Сформирована финотчётность
- **Источник:** Operations.
- **Семантика:** собран финансовый отчёт за период.
- **Контракт:**
  ```json
  { "report_id": "uuid", "period": "YYYY-MM", "domain": "string", "totals": { "revenue": "decimal", "cost": "decimal" }, "built_at": "ts" }
  ```

## Соглашения по контрактам
- Версионирование через Schema Registry; обратная совместимость проверяется в CI/CD.
- Доставка at-least-once + идемпотентные консьюмеры (дедуп по `event_id`/доменному ключу).
- Необрабатываемые сообщения → DLQ.
- Чувствительные медданные (медкарты, снимки, результаты исследований по существу) в события аналитики не включаются — только факты и метаданные.
