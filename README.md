# architecture-future_2_0

Проектная работа спринта 11 для компании «Будущее 2.0».

| Каталог | Результат |
|---|---|
| [Task1](./Task1) | C4 Container целевой архитектуры, проблемные места и их приоритизация |
| [Task2](./Task2) | Разделение на домены, DFD и обоснование границ |
| [Task3](./Task3) | Технологический радар, роадмап и бизнес-обоснование этапов |
| [Task4](./Task4) | Terraform-конфигурация IaaS, схема автоматизации и обоснование |

Медицинские карты, истории болезни и результаты исследований исключены из
аналитической витрины. В репозитории используются только демонстрационные значения;
учётные данные передаются через переменные окружения.

## Проверка перед сдачей

- `terraform fmt -check` и `terraform validate` выполнены успешно.
- В `Task4/terraform.tfvars` нужно подставить идентификаторы своего Yandex Cloud и
  публичный SSH-ключ, выполнить `terraform plan` и `terraform apply`.
- Скриншот успешного применения нужно сохранить как `Task4/apply-result.png`.
